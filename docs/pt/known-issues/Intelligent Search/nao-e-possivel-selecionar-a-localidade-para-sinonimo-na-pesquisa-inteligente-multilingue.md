## Sumário

Para lojas multilíngues, a Busca Inteligente permite selecionar a localidade ou configurá-la para se aplicar a todas as localidades ao criar/editar sinônimos.

No entanto, quando a loja está configurada para 2 (duas) localidades, o formulário de criação/edição de um sinônimo trava e permite apenas a opção "Todas", o que significa que o sinônimo será aplicado a todas as localidades.

## Simulação

Os passos para simular o Problema Conhecido são:

- Abra o formulário para criar ou editar um sinônimo.

- No campo _Localidade_, selecione qualquer opção diferente de **Todas**.

**Resultado esperado:** O campo _Localidade_ muda para a opção selecionada.

**Resultado real:** O campo _Localidade_ não muda para a opção selecionada.
