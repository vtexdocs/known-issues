## Sumário

Ao tentar cadastrar o primeiro endereço nesta conta, através de "Minha Conta > Endereços", é exibida a informação de que é "obrigatório" inserir os "Dados do Terceiro Autorizado". No entanto, mesmo após inserir essas informações e clicar em "Cadastrar Endereço", o endereço não é cadastrado e a mensagem de que é "obrigatório" é exibida novamente. Somente após a segunda tentativa o endereço é salvo com sucesso.

## Simulação

Para simular este caso, é necessário cadastrar o primeiro endereço em "Minha Conta > Endereços", inserir as informações dos "Dados do Terceiro Autorizado". Neste momento, você notará este comportamento, sendo necessárias duas tentativas para salvar os dados.

## Workaround

Nesses casos, será necessário fazer duas ou mais tentativas para salvar os dados.
