## Sumário

Alguns números de celular argentinos específicos estão sendo exibidos incorretamente. O comprador vê dígitos repetidos na tela, o número errado é salvo no pedido e, ao tentar corrigi-lo, recebe uma mensagem informando que o número é internacional, o que não é verdade.

## Simulação

- Abra um carrinho na conta afetada na Argentina.
- Digite o número de celular 0 3854 1111111.
- O número é exibido incorretamente na tela, com alguns dígitos repetidos.

- O número errado é salvo no pedido.

- Edite o campo para inserir o número correto — uma mensagem informa que o número é internacional.
