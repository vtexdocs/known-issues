## Sumário

A pré-visualização do frete na página do carrinho não funciona quando itens com entrega padrão e itens com entrega agendada estão no mesmo carrinho. Um valor indefinido é exibido para o item com entrega agendada.

## Simulação

- Acesse a etapa de frete no checkout.
- Use o CEP 22250040.
- A pré-visualização do frete mostra um valor indefinido para o item com entrega agendada.
