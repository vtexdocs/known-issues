## Sumário

Ao tentar publicar um aplicativo, você pode encontrar um erro do builder-hub. Essa intermitência normalmente ocorre em aplicativos com dependências próprias. Você pode ver um dos seguintes erros:

erro: node@4.x builder falhou ao instalar dependências através do yarn (tentativas=3) erros do yarn: Ocorreu um erro inesperado: "http://.vtexassets.com/_v/public/typings/v1//public/@types/: Falha na solicitação \"500 Erro Interno do Servidor\"". vtex.builder-hub@0.309.0

OU

Falha ao buscar dados de compilação de páginas para <app>@<versão>. Causado por: tempo limite de XXXXms excedido

## Simulação

Não é um problema simples de reproduzir; ele é intermitente.

A melhor maneira de verificar problemas intermitentes é observar se outros aplicativos estão apresentando falhas durante o mesmo período em #vtex-io-3p-releases

## Workaround

Este problema pode ser resolvido após algumas tentativas, mas se persistir, abra um chamado para o Suporte ao Produto para obter ajuda.
