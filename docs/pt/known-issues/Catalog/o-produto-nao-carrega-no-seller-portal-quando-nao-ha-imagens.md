## Sumário

Para contas do Seller Portal, se você tiver um produto sem imagens para cada SKU, a interface do produto não carregará corretamente.

## Simulação

1. Crie um produto sem imagens em todos os seus SKUs usando o painel de administração do Seller Portal ( /admin/products ).
2. Tente acessar as informações do produto; os dados continuarão carregando indefinidamente.

## Workaround

Adicione imagens aos itens.
