## Sumário

O simulador de frete não funciona com pontos de coleta em países que não utilizam nossa API de CEP.

Para verificar se um país utiliza nossa API de CEP, entre em contato com o suporte.

## Simulação

Faça uma simulação de frete (/admin/logistics#/freight-simulation) e o ponto de coleta não aparecerá como opção.

## Workaround

Isso não afetará a operação do ponto de coleta na loja, e o ponto de coleta deverá funcionar corretamente no checkout.
