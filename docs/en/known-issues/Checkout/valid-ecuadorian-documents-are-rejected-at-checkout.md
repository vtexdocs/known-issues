## Summary

Valid Ecuadorian document numbers are accepted by the checkout screen but are rejected when the buyer tries to finish the purchase. An error message pops up, and the order is not placed.

## Simulation

1. Open a cart on an Ecuador account.
2. Fill the document field with 3040087375 — the field accepts it.
3. Try to finish the purchase — an error message pops up, and the order is not placed.

## Workaround

There is no workaround available.
