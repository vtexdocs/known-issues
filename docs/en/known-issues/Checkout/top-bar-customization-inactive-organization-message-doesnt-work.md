## Summary

The Top Bar Custom organization settings, which should change message and color of the top bar shown for users logged in Inactive Organizations, doesn't work.

## Simulation

1. On the account's admin, go to Apps > B2B Organizations & Cost Centers > Settings
2. On the "Personalização da Barra Superior" block, change the color and message
3. Log in to an inactive organization. The Custom Top Bar won't be shown; only the default message of the User Widget is rendered
