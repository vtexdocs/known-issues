## Summary

Some specific Argentine mobile phone numbers are broken up incorrectly. The buyer sees digits repeated on the screen, the wrong number is saved to the order, and trying to correct it returns a message saying the number is international, which it is not.

## Simulation

- Open a cart in the affected account in Argentina
- Enter the mobile phone number 0 3854 1111111.
- The number is shown incorrectly on screen, with some digits repeated.
- The wrong number is saved to the order.
- Edit the field to enter the correct number — a message says the number is international.
