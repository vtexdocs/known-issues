## Summary

When the store has a fixed freight or the products have the same freight value, removing a product from the cart shows the pop-up "Freight value has changed", even though the final freight value does not change.

## Simulation

1. Go to the affected checkout account
2. Remove one item.
3. The pop-up "Freight value has changed" is shown, and the final freight value stays the same.
