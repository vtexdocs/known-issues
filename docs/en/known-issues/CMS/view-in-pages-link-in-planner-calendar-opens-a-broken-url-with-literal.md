## Summary

When opening the options menu for a content update item inside a release in the Planner Calendar (`/admin/planner/calendar`) and clicking "View in Pages", the user is redirected to a URL where the `` placeholder was not substituted, resulting in a broken link (e.g. `https://.myvtex.com/admin/new-cms//plp/edit/<id>`). The issue affects any content type listed in the release (PLP, Home, collections, etc.), not just one specific type.

## Simulation

1. Access the Planner Calendar (`/admin/planner/calendar`) on an account with Headless CMS.
2. Navigate to a day that has a release with at least one content update (e.g. a Home or PLP item).
3. In the release's update list, click the options menu (three-dot icon) for any item.
4. Click "View in Pages" (for already published items) or "Edit".
5. Note that the opened tab shows a URL with a literal `` instead of the actual account name, resulting in a page-not-found.

## Workaround

There is no workaround through the UI. As a manual alternative, the user can edit the broken URL directly in the browser's address bar, replacing the literal `` with the actual account name (and, if on a workspace other than `master`, prefixing it as `{workspace}--{account}`), then reload the page. Alternatively, the user can navigate manually to the correct content item via the Storefront menu > Headless CMS, using the item's name/type shown in the release as a reference, instead of using the link generated by the Planner.
