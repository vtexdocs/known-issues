## Sumario

La vista previa de envío en la página del carrito no funciona cuando hay artículos con envío estándar y artículos con envío programado en el mismo carrito. Se muestra un valor indefinido para el envío programado.

## Simulación

- Vaya al paso de envío al finalizar la compra.
- Use el código postal 22250040.
- La vista previa de envío muestra un valor indefinido para el artículo con envío programado.
