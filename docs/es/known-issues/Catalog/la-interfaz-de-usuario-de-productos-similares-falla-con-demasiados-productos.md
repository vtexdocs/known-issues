## Sumario

Al abrir un formulario de producto con más de 6 productos similares, la visualización de la interfaz de usuario falla.

Para que se muestre en formato de lista, comienza a agregarse en formato de escalera.

## Simulación

Agregar 10 productos similares a un producto.

## Workaround

- Recomendamos usar la API para gestionar los productos similares.
- Intente minimizar el zoom de la página; esto ayuda a que se ajuste mejor y funciona en algunos casos.
