## Sumario

Al intentar publicar una aplicación, puede aparecer un error de builder-hub. Esta intermitencia suele ocurrir en aplicaciones con autodependencias. Puede que vea uno de los siguientes errores:

Error: el generador de node@4.x no pudo instalar las dependencias mediante yarn (intentos = 3). Errores de yarn: Se produjo un error inesperado: "http://.vtexassets.com/_v/public/typings/v1//public/@types/: La solicitud falló "500 Error interno del servidor". vtex.builder-hub@0.309.0

O

No se pudieron obtener los datos de compilación de las páginas para <app>@<version>. Causa: se superó el tiempo de espera de XXXX ms.

## Simulación

No es un problema fácil de reproducir; es intermitente. La mejor manera de detectar problemas intermitentes es comprobar si otras aplicaciones fallan durante el mismo período de tiempo en #vtex-io-3p-releases

## Workaround

Es posible que se solucione tras varios intentos, pero si el problema persiste, abre una incidencia con el soporte técnico para que lo resuelvan.
