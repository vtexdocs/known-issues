## Sumario

En tiendas multilingües, la Búsqueda Inteligente permite seleccionar la configuración regional o aplicarla a todas las configuraciones regionales al crear o editar sinónimos.

Sin embargo, cuando la tienda está configurada para dos configuraciones regionales, el formulario para crear o editar un sinónimo se bloquea y solo permite la opción «Todas», lo que significa que el sinónimo se aplicará a todas las configuraciones regionales.

## Simulación

Los pasos para simular el problema conocido son:

- Abra el formulario para crear o editar un sinónimo.

- En el campo «Configuración regional», seleccione cualquier opción que no sea «Todas».

**Resultado esperado:** El campo «Configuración regional» cambia a la opción seleccionada.

**Resultado real:** El campo «Configuración regional» no cambia a la opción seleccionada.
