## Sumario

El simulador de envíos no funciona con puntos de recogida en países que no utilizan nuestra API de códigos postales.

Para comprobar si un país utiliza nuestra API de códigos postales, debe ponerse en contacto con el servicio de asistencia.

## Simulación

Realice una simulación de envío (/admin/logistics#/freight-simulation) y el punto de recogida no aparecerá como opción.

## Workaround

Esto no afectará al funcionamiento del punto de recogida en la tienda y debería funcionar correctamente en el proceso de pago.
